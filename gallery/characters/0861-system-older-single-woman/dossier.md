# 县城体制内大龄剩女 · 人物档案

原型/复合群像，非单一自然人。核心是县城婚恋市场筛选后被剩下的“体制内大龄剩女”群体标签：有编制、条件被称县城第一梯队，却不降择偶要求，靠父母人脉广撒网找人介绍。另有大龄剩女泛称与教师、护士、银行女三大重灾区两条补充线，均未落到个体生平。

版本一（#203）：a男娶b女层层向下后，最后剩下农村大龄剩男与县城体制内大龄剩女，两者是最不会搞对象与最难搞的一对，无机会在相亲市场碰面；该群体不降要求，发力方向是广撒网、疯狂找人介绍，父母一辈子人脉全押上；出嫁时父母流泪，像考编上岸一样终于送走。版本二（#128）：县城70%以上大龄剩女来自教师、护士、银行女，成因分别是特殊圈层致自我认知失准、特殊经历致性格缺陷、特殊环境致异性资源匮乏。版本三（泛称#231/#383/#419/#523）：年龄越大要求越苛刻、开局问房车彩礼，死撑价格等待高价买者、可能砸在手里，要求对方最短短板长于自己最长长板，只有骗子才能满足、易被杀猪盘收割。

## 人物故事

**县城相亲角的塑料凳**

县城最南边到最北边，开车用不了20分钟。可就是在这20分钟能跑完的地方，相亲市场上女性数量碾压男性。有人干脆说，有的相亲角“甚至都已经不收女性的资料了”。就在这样一个连距离都要卡的地方——房子买在多层还是高层要纳入考虑，离她上班的地方多远也要算——最后筛出来的，是“农村的大龄剩男”和“县城体制内的大龄剩女”。“而这两个群体是没有任何机会在相亲市场上碰面的。”

**70%以上和三个职业**

教师、护士、银行女。材料里说，“县城里70%以上的大龄剩女都来自于这三个群体”。银行女被单独拎出来，理由是“从事这个行业就是跟钱打交道的，所以时间久了自然就会对钱失去概念”。原话给了一个对比：一个普通人“一个月收入万儿八千的水平”，却“接触到几百万几百万的数字”，“她自然就看不上那个月入5000的老公了”。教师那边则是一套反向的说法：工作环境里“除了你之外，别人全是文盲”，久了“听不进别人的意见”。护士的说法落在异性资源上——第一梯队里“能够女护士选择的，可能连30%都没剩下”。三个职业，三条因果，各说各的，原文也没说这三类人全都带编。

**保时捷和代偿**

县城攀比靠的是信息传递效率，“比自媒体还快”。一个女老师谈了个开保时捷的对象，“不出一个月”，闺蜜、朋友、同事、“全县城所有的未婚女老师全都知道了”；“不出两个月”，女公务员、女事业编、银行女职工，找对象的内心设定“全都是得开保时捷”。但这个条件“不会拿到明面上来说”——没人会开口就要求保时捷，“那会让人笑话”。它变成“对标要求”：没达到不直接刷掉，但“会在别的地方找补回来”——彩礼多要一点，节日惊喜多备一份，“这就叫代偿”。

**死撑价格**

有人问大龄剩女什么时候才意识到自己有价无市。回答是拿楼市打比方：不直接降价抛售，而是“死死撑住这个价格，去等那个可能会出现的高价买者”。撑不住的呢？原文给了两个走向：一个是“绝大多数大龄剩女最后面临的情况跟农村的大龄剩男一样，就是会砸在手里”；另一个是杀猪盘——“只有骗子才能满足他们的择偶要求”。至于要求本身，版本也不统一：一版说“年龄越大要求越苛刻，开局就问你有房吗？有车吗？彩礼准备掏多少？”另一版说“对方最短的那个短板也要比自己的长板更长”。

**广撒网和考编上岸**

她们被叫“最难搞的一帮女人”。原话的逻辑很硬：“她们是不会降低要求的，因为但凡他们降低要求，他们就不会剩下了。”发力方向是“广撒网”，“疯狂的找人介绍对象”，“基本上就是父母的资源大战，一辈子攒的那点人脉全都用在这事上了”。至于最后——一个版本是出嫁那天，爹妈“哭哭的流眼泪”，“根本不是心疼闺女出嫁，那就跟考编上岸一样，终于送走了”。另一个版本里，人根本没送走，砸在手里了。
